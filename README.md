# JARVIS · CGL System

Site cinematográfico (rolagem que toca um vídeo) do assistente de IA Jarvis.

- `site/`: o site estático (abra com `python -m http.server 4173` dentro da pasta)
- `fonte/`: vídeo e imagens originais usados para gerar o site
- `backup-antes-splash/`: versão anterior, sem a tela de entrada
